# Pruebas

Guarda aquí los documentos que sustentan los hechos: contratos, cartas, constancias, historias clínicas, recibos, correos, actos administrativos.

**Reglas:**

- Un archivo por prueba, con el nombre `P-01-descripcion.md` o `.pdf`.
- No guardes datos reales sin anonimizar.
- Cada prueba debe estar descrita en `01-entrada/entrevista-y-pruebas.md` y en `02-hechos/hechos.md`.
- Si el documento es un PDF escaneado sin texto, transcribe el pasaje que se va a citar.
